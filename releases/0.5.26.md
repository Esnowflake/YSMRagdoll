# YSM Ragdoll 0.5.26 — 柔性牵引与自然关节摆动

适用于 Minecraft **1.20.1 Forge 47.4.x**，需要 **Java 17** 和兼容的 YSM 模组（已验证 YSM 2.6.5）。

## 本版更新

- “测试”分类新增 **牵引线力矩（0–100）**，默认 **70**。0 无法牵引；1–99 使用有最大拉力限制的柔性牵引，数值越低越柔软，过低时可能无法提起；100 刚性跟随、牵引线笔直，仍受方块阻挡。
- 拉力只施加到实际抓取点，通过关节传递到身体和四肢。牵引时仍能自然下垂、弯曲和摆动，布娃娃自身的线性阻尼、角阻尼及关节角度限制保持不变。
- 保留关节防脱节保护，改善轻质肢体受牵引时的连接稳定性；修复连续小幅连接修正可能挤入方块的问题。
- 牵引线玩家端延伸到主手木棍附近，颜色更新为 **#33FFCC**。曲线跟随布娃娃实际滞后，跟上目标后逐渐拉直，限制末端翘起及回折。
- 包含 0.5.25 的液体浮力、松手惯性，以及布娃娃管理、碰撞缓存和 Y < -64 虚空清理功能。

## 使用方式

在设置的“测试”分类开启“牵引模式”，主手拿木棍，瞄准布娃娃 **按住右键牵引、松开释放**；滚轮调距。修改力矩后点击“应用”或“确定”保存。切换物品或打开界面会结束牵引。

## 安装与回退

下载本 Release 的 **ysmragdoll-0.5.26-all.jar**，退出游戏后替换实例 `mods` 中的旧版文件。只保留一份 YSM Ragdoll，不要同时安装新旧版本。普通小体积 JAR 和 Source code 压缩包不是完整安装包。

源码标签为 **0.5.26**。旧版标签和附件保留，需要回退时可使用 [0.5.25 Release](https://github.com/Esnowflake/YSMRagdoll/releases/tag/0.5.25)。
